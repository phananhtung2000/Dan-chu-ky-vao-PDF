Bấm nút trên để tạm ẩn khung/nút chỉnh, xem chữ ký đúng như khi in ra PDF. Bấm lại để quay về chỉnh tiếp.

Bấm nút trên rồi tô/vẽ trực tiếp lên vùng chữ hoặc chi tiết cần xóa trên trang xem trước — nét vẽ sẽ phủ trắng đúng chỗ đó khi lưu file. Bấm lại nút để tắt bút tẩy và quay về kéo/chỉnh chữ ký như bình thường.

Độ dày nét 3%

Chất lượng file xuất

Mức "Cao" giữ nguyên chất lượng như trước. Chọn "Vừa" hoặc "Nhẹ" để file nhỏ hơn, dễ gửi qua email.

Mẹo: bấm Ctrl+S để lưu nhanh file PDF, Ctrl+Shift+S để lưu nhanh ảnh JPG — không cần rê chuột xuống nút.
